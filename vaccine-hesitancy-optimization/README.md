# Optimizing Vaccination Strategies and Reducing Vaccine Hesitancy

## Overview
This repository is part of a unified research framework designed to strengthen epidemic preparedness and response. 
It provides reproducible mathematical and computational models to guide policy design, resource allocation, and outbreak forecasting.

## Project Description
Optimizing Vaccination Strategies and Reducing Vaccine Hesitancy is focused on developing transparent, data-driven models that directly support decision-making by U.S. public health agencies. 
All code, documentation, and example data are provided to ensure reproducibility and open access.

## Folder Structure
- **models/** – MATLAB/Python scripts implementing model equations and algorithms.
- **data/** – Example datasets or public data sources.
- **figures/** – Visual results and conceptual diagrams.
- **docs/** – Policy briefs, methodology notes, and technical documentation.
- **results/** – Simulation outputs and summaries.

## How to Use
1. Clone the repository:  
   ```bash
   git clone https://github.com/yourusername/vaccine-hesitancy-optimization.git
   ```
2. Navigate into the folder and open scripts in MATLAB or Python.
3. Follow the `README.md` instructions in each model subdirectory.
